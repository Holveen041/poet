# Тема поэта и поэзии — статическая версия

Полная копия React-проекта на чистых HTML, CSS и JavaScript. Без сборки,
зависимостей и Node.js: достаточно открыть `index.html` или загрузить папку
на GitHub Pages.

## Что внутри

```
index.html          разметка страницы, meta-теги, подключение стилей и скриптов
css/styles.css      все стили (палитра, типографика, адаптив)
js/data.js          тексты разделов, вопросы викторины, слова кроссворда
js/app.js           навигация, интерактивные блоки, викторина, кроссворд
images/             сюда можно положить иллюстрации (см. images/README.txt)
```

## Локальный просмотр

Откройте `index.html` двойным щелчком — сайт работает и по протоколу `file://`.

Если нужен локальный сервер (например, для проверки как на хостинге):

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория содержимое этой папки так, чтобы `index.html`
   лежал в корне (не во вложенной папке).
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Deploy from a branch**,
   ветку `main` и папку `/ (root)`. Сохраните.
5. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`.

Все пути относительные (`css/...`, `js/...`, `images/...`), поэтому сайт
корректно работает и в корне домена, и в подпапке репозитория.

## Иллюстрации

В исходной версии слоты для картинок были пустыми и показывали рамку-заглушку.
Здесь поведение то же: если файла нет, отображается заглушка с путём. Чтобы
иллюстрации появились, положите файлы в папку `images/` с такими именами:

- `pushkin-mikhailovskoe.jpg` — раздел 01, картина «Пушкин в Михайловском»
- `poet-and-crowd.jpg` — раздел 02, сцена 4:3
- `pushkin-exile.jpg` — раздел 03, живопись
- `pushkin-manuscript.jpg` — раздел 04, рукопись
- `poetry-xx-xxi.jpg` — раздел 05, фотография 4:3

### Как кадрируется картинка

По умолчанию картинка заполняет рамку (`object-fit: cover`), то есть при другой
пропорции края обрезаются. Если обрезка нежелательна, для слота включается
режим «показать целиком»:

```js
figureSlot({
  src: 'images/pushkin-mikhailovskoe.jpg',
  // ...
  fit: 'contain',      // рамка подстроится под пропорции файла, без обрезки
  ratioCss: '550 / 379' // пропорции файла: резервируют место до загрузки
})
```

Так сделано для картины «Пушкин в Михайловском»: файл горизонтальный, а слот
задуман вертикальным, поэтому при `cover` от живописи оставалась бы лишь
середина. `ratioCss` нужен только чтобы вёрстка не прыгала в момент загрузки —
поставьте `ширина / высота` своей картинки в пикселях.

## Управление

- Разделы переключаются кликом по меню, кнопками «Назад / Далее» и клавишами
  ← и → (когда фокус не в поле ввода).
- В викторине 8 вопросов: ответ проверяется сразу, в конце показывается итог.
- В кроссворде 10 слов (14 × 16 клеток): слова закрепляются автоматически,
  есть подсказка «Открыть букву» и проверка ответов.
